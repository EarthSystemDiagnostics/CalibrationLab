# ============================================================
#  Transient sweep  -  drive the bath up/down (no dwell) to characterise the
#  bath + sensor dynamic response and validate token-accurate per-value logging.
#  Run with:  python3 calibration_auto.py --param param_transient.txt --dashboard
#
#  How it works: gate_mode=fixed + plateau_minutes=0 + a tiny stability window ->
#  the run ramps to each setpoint, counts it as "arrived" and reverses at once, so
#  the setpoints become the APEXES of a triangle wave (no plateau). The continuous
#  NTC+SPRT+TOFFMS stream is the dataset; plateaus.txt just marks the apex times.
#
#  Two ramp rates (1 then 2 C/min) over the same range: the up-vs-down hysteresis
#  scales as 2*dTau*rate, so extrapolating rate->0 gives the lag-free calibration
#  and reveals how flat a real plateau must be.
# ============================================================
